## 🚀 Rules for Going Forward

### ✅ MUST DO:
1. All documentation goes in `docs/` folder
2. Phase files → `docs/phases/`
3. Guide files → `docs/guides/`
4. API docs → `docs/api/`
5. Session records → `docs/sessions/`
6. Follow naming conventions
7. Use proper markdown formatting

### ❌ MUST NOT DO:
- Create .md files in root folder
- Mix different types of docs
- Put docs in src/ or scripts/ folders
- Ignore subfolder organization

### Example (Correct Way):
```
✅ CORRECT:
   docs/phases/PHASE_2_2_AUTHENTICATION.md
   docs/guides/USER_REGISTRATION_GUIDE.md
   docs/api/PATIENT_ENDPOINTS.md

❌ WRONG:
   PHASE_2_2_AUTHENTICATION.md (in root)
   docs/USER_REGISTRATION_GUIDE.md (not in guides/)
   docs/PATIENT_ENDPOINTS.md (not in api/)
```
