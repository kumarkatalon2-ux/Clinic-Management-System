OBJECTIVE
---------
Implement doctor personal scheduling system managing individual doctor's working
hours, calendar, availability, leave/vacation, and personal preferences.

BUSINESS LOGIC
--------------
Doctor Schedule Purpose:

Each doctor has unique schedule:

Dr. Smith:
  - Monday-Friday: 8am-5pm
  - Saturday: Off
  - Lunch: 12-1pm daily
  - Vacation: March 15-25
  - Prefers: Morning appointments
  - Max patients: 20 per day

Dr. Johnson:
  - Monday-Wednesday: 9am-3pm (part-time)
  - Thursday-Friday: 8am-5pm
  - No Saturday
  - Vacation: Spring (entire April)
  - Prefers: Complex cases, longer visits
  - Max patients: 15 per day

Scheduler must track all this information to:
1. Show correct availability to patients
2. Prevent overbooking
3. Respect doctor preferences
4. Handle absences (vacation, sick leave)
5. Manage part-time vs full-time

DOCTOR SCHEDULE DATA MODEL
--------------------------
Doctor Base Info:

CREATE TABLE doctors (
  id UUID PRIMARY KEY,
  clinic_id UUID NOT NULL,
  tenant_id UUID NOT NULL,
  user_id UUID NOT NULL,
  
  first_name VARCHAR(100),
  last_name VARCHAR(100),
  specialty VARCHAR(100),
  
  -- Licensing
  npi VARCHAR(10),
  license_number VARCHAR(50),
  license_state VARCHAR(50),
  
  -- Credentials
  credentials TEXT,  -- "MD, Board Certified in Family Medicine"
  
  -- Capacity
  max_patients_per_day INT DEFAULT 20,
  accepting_new_patients BOOLEAN DEFAULT true,
  
  -- Status
  is_active BOOLEAN DEFAULT true,
  hire_date DATE,
  termination_date DATE,
  
  created_at TIMESTAMP,
  updated_at TIMESTAMP
);

Weekly Schedule:

CREATE TABLE doctor_weekly_schedules (
  id UUID PRIMARY KEY,
  doctor_id UUID NOT NULL,
  clinic_id UUID NOT NULL,
  
  -- Which week (usually Monday of week)
  week_start_date DATE,
  
  -- Monday
  monday_is_working BOOLEAN,
  monday_start_time TIME,  -- 08:00
  monday_end_time TIME,    -- 17:00
  monday_lunch_start TIME, -- 12:00
  monday_lunch_end TIME,   -- 13:00
  
  -- Tuesday (same structure)
  tuesday_is_working BOOLEAN,
  tuesday_start_time TIME,
  tuesday_end_time TIME,
  tuesday_lunch_start TIME,
  tuesday_lunch_end TIME,
  
  -- ... Wednesday through Sunday
  
  -- Notes
  notes TEXT,  -- "Partial day (conference 2-3pm)"
  
  UNIQUE(doctor_id, week_start_date)
);

LEAVE & ABSENCE MANAGEMENT
--------------------------
Leave Types:

1. VACATION
   - Planned time off (1-2 weeks)
   - Doctor chooses dates
   - Must request advance notice
   - Replacement coverage arranged

2. SICK LEAVE
   - Unplanned absence
   - Doctor calls in morning
   - Same-day notice
   - Appointments rescheduled

3. CONFERENCE
   - Professional development
   - Doctor at conference
   - Planned advance
   - May be partial week

4. TRAINING
   - New procedure training
   - New staff training
   - Planned advance

5. PERSONAL
   - Personal appointments
   - Doctor absence during work hours
   - Impacts scheduling

6. UNPAID LEAVE
   - Extended absence
   - Educational leave
   - Family leave

Leave Table:

CREATE TABLE doctor_leaves (
  id UUID PRIMARY KEY,
  doctor_id UUID NOT NULL,
  clinic_id UUID NOT NULL,
  
  leave_type VARCHAR(50),
  -- VACATION, SICK, CONFERENCE, TRAINING, PERSONAL, UNPAID
  
  start_date DATE,
  end_date DATE,
  
  reason TEXT,  -- "Family emergency", "Annual vacation", etc.
  
  status VARCHAR(50),
  -- REQUESTED, APPROVED, REJECTED, CANCELLED
  
  requested_at TIMESTAMP,
  requested_by UUID,
  
  approved_at TIMESTAMP,
  approved_by UUID,  -- Manager approval
  
  replacement_doctor_id UUID,  -- Who covers?
  
  created_at TIMESTAMP,
  updated_at TIMESTAMP
);

Leave Request Flow:

1. REQUEST
   Doctor submits leave request:

   POST /doctors/uuid-dr-smith/leaves
   {
     "leaveType": "VACATION",
     "startDate": "2024-03-15",
     "endDate": "2024-03-25",
     "reason": "Family vacation",
     "replacementDoctorId": "uuid-dr-johnson"
   }

2. APPROVAL
   Manager reviews:

   PATCH /doctors/uuid-dr-smith/leaves/uuid-leave-123
   {
     "status": "APPROVED",
     "replacementDoctorId": "uuid-dr-johnson"
   }

3. IMPACT ON SCHEDULING
   System:
   - Blocks all dates (March 15-25)
   - Reschedules existing appointments to Dr. Johnson
   - Notifies patients: "Your appointment moved to Dr. Johnson"
   - Updates slot availability

4. COVERAGE
   Dr. Johnson covers:
   - Accepts Dr. Smith's patients
   - Extra appointments that week
   - Patient notification sent

Sick Leave (Same-Day):

Doctor calls at 8am: "I'm sick, can't work today"

POST /doctors/uuid-dr-smith/leaves
{
  "leaveType": "SICK",
  "startDate": "2024-02-15",
  "endDate": "2024-02-15",
  "reason": "Flu",
  "status": "APPROVED"  // Auto-approved for same-day
}

System:
- Marks Dr. Smith unavailable for Feb 15
- Finds all appointments that day (8am-5pm)
- For each appointment:
  - Find replacement doctor available at same time
  - Reschedule patient
  - Send notification: "Your appointment has been rescheduled"

DOCTOR PREFERENCES
------------------
Doctor Preferences Table:

CREATE TABLE doctor_preferences (
  id UUID PRIMARY KEY,
  doctor_id UUID NOT NULL,
  clinic_id UUID NOT NULL,
  
  -- Scheduling Preferences
  prefers_morning_appointments BOOLEAN,
  prefers_afternoon_appointments BOOLEAN,
  min_appointment_duration_minutes INT,  -- Won't see patients <20min
  
  -- Patient Preferences
  prefers_new_patients BOOLEAN,
  prefers_follow_ups BOOLEAN,
  prefers_procedures BOOLEAN,
  
  -- Break Preferences
  lunch_start_time TIME,  -- Flexible lunch time
  lunch_duration_minutes INT,
  
  -- Load Preferences
  max_patients_per_day INT,
  max_procedures_per_week INT,
  
  -- Other
  notes TEXT,
  
  updated_at TIMESTAMP
);

Example Preferences - Dr. Smith:

{
  "doctorId": "uuid-dr-smith",
  "preferences": {
    "scheduling": {
      "prefersMoreMorningAppointments": true,
      "minAppointmentDuration": 20,
      "maxPatientsPerDay": 20
    },
    "patients": {
      "acceptsNewPatients": true,
      "prefersFollowUps": false,  // Likes variety
      "acceptsProcedures": true
    },
    "breaks": {
      "lunchStartTime": "12:00",
      "lunchDurationMinutes": 60
    },
    "restrictions": {
      "maxProceduresPerWeek": 5,
      "noAppointmentsAfter": "16:00"  // Leaves at 4pm to do admin
    }
  }
}

Impact on Scheduling:

When scheduling:
- Dr. Smith prefers morning → Offer morning slots first
- Max 20 patients/day → After 20 booked, no more
- No appointments after 4pm → Block 4-5pm slots
- Prefers follow-ups → Could filter suggestions
